# Decision Explanation Examples

Generated by `python scripts/generate_examples.py` from real runs of the platform. Each example shows the input, the rules that fired, the output and the audit reasoning. The same data is available live from `GET /requests/{id}/explanation`.

Simulator demo knobs used below: `CS<score>` in an applicant id forces that credit score, `RISK<n>` in a claim id forces that fraud score, `FLAKY` makes the service time out twice, `SLOW` makes it answer after 5 s (past the 2 s deadline), `DOWN` makes it always unavailable.
